- **Интерфейс игры: что стоит знать** (автор 11.10.2026 просил записывать всё такое сюда, а не только говорить):
  - Высота экрана в единицах — поле `height` у `canvas` (как Canvas Scaler), у каждого Canvas своя. В
    `project.json` поля `uiHeight` больше нет: если оно там осталось, `check` назовёт его неизвестным, а
    значение не действует. У `height` один режим — «по высоте экрана»; подгонки по ширине и «постоянного
    размера в пикселях», как у Canvas Scaler, нет.
  - Сцена с интерфейсом, сделанная до Canvas (корневой объект с `ui` нулевого размера), ничего не рисует, пока
    корневой объект не получит `canvas`. Демо-сцена `ui` переведена.
  - Add Component не переносит объект в Canvas: `text` на объекте вне Canvas получает `ui`, но на экране его
    нет, и редактор об этом молчит — скажет только `check`.
  - В префабе `check` не требует Canvas (префаб одной кнопки допустим): элемент из экземпляра, поставленного
    вне Canvas, молча не рисуется.
  - Canvas внутри Canvas — новый экран со своим `height`, а не часть родителя.
  - У Canvas нет порядка рисования: кто ниже в Hierarchy, тот поверх.
